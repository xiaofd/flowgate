# FlowGate

> 轻量级网络连接管理工具 —— 单文件、一键运行、开机自启。

FlowGate 是一个跨平台的轻量网络工具，用于改善部分网站与开发资源站的访问体验。它只处理需要优化的连接，日常使用（网页浏览、P2P 等）不受任何影响。

## 特性

- **单文件即用** —— 一个可执行文件搞定一切，无需安装依赖
- **一键初始化** —— `setup` 自动完成全部环境准备（含所需组件的自动下载与安装）
- **按需优化** —— 仅处理需要优化的目标（含 GitHub / PyPI / npm / Go / Docker Hub 等开发资源站），其余连接不受影响
- **双平台** —— Windows 与 Linux 命令行一键运行
- **持久化运行** —— 可安装为系统服务，开机自启、崩溃自动重启
- **交互控制台** —— 双击运行即进入中文交互菜单，零门槛使用
- **纯净卸载** —— `uninstall --purge` 一键还原系统原状
- **自动更新** —— `update` 一键更新

## 快速开始

从 [Releases](../../releases) 下载对应平台的可执行文件。

**双击运行**（Windows）直接进入交互菜单；或使用命令行：

```bash
flowgate setup      # 初始化环境（首次使用必执行）
flowgate install    # 安装为系统服务：开机自启 + 崩溃自动重启（推荐）
flowgate status     # 查看运行状态
flowgate doctor     # 全面自检
flowgate update     # 一键更新
```

前台体验：`flowgate run`（Ctrl+C 优雅退出并自动恢复网络设置）。

## 命令速查

| 命令 | 说明 |
|---|---|
| `setup` | 初始化 / 修复环境 |
| `run` | 前台运行 |
| `install` / `uninstall` | 安装 / 卸载系统服务（`--purge` 彻底清理） |
| `start` / `stop` / `restart` | 服务控制 |
| `status` / `doctor` / `logs` | 状态 / 自检 / 日志 |
| `update` | 更新组件 |
| （无参数） | 进入交互控制台 |

## 系统要求

- Windows 10+（amd64）或 Linux（amd64 / arm64）
- 管理员 / root 权限（首次运行会自动请求提权）
- 网络可访问外部服务

## 说明

- 退出或异常终止后，所有网络设置自动恢复原状
- 基于免费公共服务，无需注册账号
